# ==============================================================================
# SECTION 1: NETWORK CONFIGURATION & PRE-REQUISITES (VIRTUALBOX)
# ==============================================================================

# By default, VirtualBox uses NAT mode, which prevents external SSH connections.
# Change VirtualBox Network Settings:
# Devices -> Network -> Network Settings -> Change "Attached to:" from NAT to "Bridged Adapter"

# After changing to Bridged Adapter, reboot the Linux VM to acquire a new IP address:
reboot


# ==============================================================================
# SECTION 2: CHECKING ASSIGNED IP ADDRESS ON LINUX SERVERS
# ==============================================================================

# Check IP address on CentOS / RedHat / RHEL systems:
ifconfig

# Check IP address on Ubuntu / Debian systems:
ip addr


# ==============================================================================
# SECTION 3: FIXING "CONNECTION REFUSED" ERROR (INSTALLING OPENSSH SERVER)
# ==============================================================================

# If SSH connection is refused, install and enable OpenSSH Server (Ubuntu / Debian):
sudo apt update
sudo apt install openssh-server -y

# Start the SSH daemon service:
sudo systemctl start ssh

# Verify SSH service status (Must show "active (running)"):
sudo systemctl status ssh


# ==============================================================================
# SECTION 4: CONNECTING VIA SSH (COMMAND LINE / TERMINAL METHODS)
# ==============================================================================

# Connect via Windows Command Prompt (CMD), PowerShell, or GitBash Terminal:
ssh paul@192.168.1.35

# Replace "paul" with your Linux username and "192.168.1.35" with your actual server IP.
# When prompted, type "yes" to accept the security certificate, then enter your user password.


# ==============================================================================
# SECTION 5: CONNECTING VIA GUI TOOLS (PuTTY & MobaXterm SETTINGS SUMMARY)
# ==============================================================================

# PuTTY Configuration:
# Host Name (or IP address) : 192.168.1.35 (your server IP)
# Port                      : 22
# Connection type           : SSH
# Action                    : Click "Open" -> Accept Fingerprint -> Enter Username & Password

# MobaXterm Configuration:
# Action                    : Click "Session" (Top-Left) -> Select "SSH"
# Remote host               : 192.168.1.35 (your server IP)
# Specify username          : Check box & enter your Linux username (e.g., paul)
# Port                      : 22
# Action                    : Click "OK" -> Enter Password
