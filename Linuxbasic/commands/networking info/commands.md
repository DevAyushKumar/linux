How to check ip of your machine ?
-> ipconfig

How to check if the server or website is accessiable or not ?
-> ping www.google.com

How to check if a IP:Port is accessiable and open or not ?
-> telnet IP port

How to check if port is open or not on our server ?
-> netstat -putan | grep 80

How to check all hubs in network path to reach a website ?
-> traceroute

How to restart our linux server ?
-> reboot

How to shutdown our linux server ?
-> shutdown
