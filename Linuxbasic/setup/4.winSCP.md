## 1. Overview & What is WinSCP?

* **WinSCP (Windows Secure Copy):** An open-source graphical SFTP, FTP, WebDAV, Amazon S3, and SCP client for Windows.
* **Core Function:** Enables secure drag-and-drop file transfers between a local Windows desktop and a remote Linux server/VM using a visual dual-pane layout.

---

## 2. Installation & Network Prerequisites

1. Download the installer from the official website `winscp.net`.
2. Complete the installer steps using **Typical Installation**.
3. Ensure your VirtualBox network settings for the target VM are set to **Bridged Adapter** so that the host Windows OS can communicate directly with the guest Linux VM.

---

## 3. Server Connection Setup

1. Launch WinSCP.
2. Configure the connection fields in the Login window:
   * **File Protocol:** `SFTP` (default) or `SCP`.
   * **Host Name:** Target Linux Server IP Address (e.g., `192.168.1.35`).
   * **Port Number:** `22` (default SSH port).
   * **User Name:** Your Linux user account name (e.g., `paul`).
   * **Password:** Linux user password.
3. Click **Save** to bookmark the session credentials for quick future logins.
4. Click **Login** $\rightarrow$ Accept the host key security certificate popup on first-time connection.

---

## 4. How to Transfer Files (Dual-Pane Interface)

* **Left Pane:** Displays local Windows directories and files.
* **Right Pane:** Displays remote Linux directories and files (default: `/home/user/`).
* **Windows to Linux Transfer:** Drag and drop files from the Left Pane to the Right Pane (or select files and press `F5`).
* **Linux to Windows Transfer:** Drag and drop files from the Right Pane to the Left Pane.
